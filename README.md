
  # Portfolio website design

  This is a code bundle for Portfolio website design. The original project is available at https://www.figma.com/design/R7ksELsbVmJhZkupja5xNR/Portfolio-website-design.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

## Validation

- `npm run typecheck` checks application and Vite configuration types, including unused declarations.
- `npm run build` runs the type check before producing the production bundle.
- `npm audit` checks installed dependencies against published security advisories.
