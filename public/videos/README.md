# Caveo Demo Video

Place your Caveo demonstration video here as `caveo-demo.mp4`.

The video will:
- Auto-play on page load
- Loop continuously
- Play muted (required for autoplay in browsers)
- Display at 650-850px height depending on screen size
- Be centered with a gradient background and glow effects

## Recommended video specifications:
- Format: MP4 (H.264 codec)
- Aspect ratio: 9:19.5 (phone screen aspect ratio)
- Resolution: 1080x2340 or higher
- File size: Keep under 10MB for optimal loading
